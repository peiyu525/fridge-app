# 規格書：冰箱食材期限管家

## 1. 專案概述
- **名稱**：冰箱食材期限管家
- **類型**：純前端單頁 Web App（單一 index.html，CSS / JavaScript 內嵌）
- **動機**：家裡冰箱常忘記食材什麼時候到期，結果過期丟掉造成浪費。希望用「圖片 + 顏色外圈」讓人一眼看出哪些食材該優先吃。
- **目標使用者**：獨居學生、小家庭、經常買菜備料的人

## 2. 核心需求
1. 記錄冰箱現有食材及其到期日
2. 每個食材有圖片（表情符號或自己上傳的照片）
3. 圖片外圈依剩餘天數顯示不同顏色提醒
4. 區分「冷藏」與「冷凍」

## 3. 功能規格

| 編號 | 功能 | 說明 |
|---|---|---|
| F1 | 新增食材 | 欄位：名稱、冷藏/冷凍、到期日、數量、圖示或照片、備註 |
| F2 | 快速選擇 | 12 種常見食材預設，一鍵帶入圖示、位置、建議保存天數 |
| F3 | 圖片 | 可輸入 emoji，或上傳照片（自動裁成正方形並縮成 200px，存於瀏覽器） |
| F4 | 顏色外圈 | 依剩餘天數顯示（見第 4 節） |
| F5 | 冷藏/冷凍分頁 | 「全部／冷藏／冷凍」切換 |
| F6 | 狀態統計 | 頂部四張卡片顯示各狀態數量，點擊可篩選，再點一次取消 |
| F7 | 搜尋 | 依名稱即時搜尋 |
| F8 | 排序 | 到期日（最快優先，預設）／名稱／最近新增 |
| F9 | 用完了 | 數量 −1，歸零則自動移除 |
| F10 | 編輯 / 刪除 | 修改任何欄位；刪除前有確認 |
| F11 | 資料保存 | 使用 localStorage，重新整理不會消失 |
| F12 | 範例資料 | 第一次開啟有 7 筆範例；可按「還原範例資料」重置 |

## 4. 顏色規則

| 剩餘天數 | 狀態 | 外圈顏色 | 額外效果 |
|---|---|---|---|
| 8 天以上 | 新鮮 | 綠色 | — |
| 3–7 天 | 快到期 | 橘黃色 | — |
| 0–2 天 | 緊急 | 紅色 | 外圈脈動動畫 |
| 已過期 | 過期 | 深褐紅色 | 圖片變灰、標示「已過期 X 天」 |

天數以「到期日 − 今天（當地時間 0 點）」計算。

## 5. 介面設計
- 上方：標題與副標
- 統計列：4 張狀態卡
- 工具列：分頁、搜尋框、排序選單、新增按鈕
- 圖例：說明四種顏色
- 主體：卡片格狀排列（RWD，手機 2 欄、桌機多欄）；每張卡片含圓形圖片 + 彩色外圈、名稱與數量、到期日、狀態標籤、冷藏/冷凍標籤、三個操作按鈕
- 新增/編輯使用彈出視窗（dialog）
- 風格：冰箱感的淡藍色系，圓角、柔和陰影

## 6. 資料結構
```json
{
  "id": 1729000000000,
  "name": "牛奶",
  "emoji": "🥛",
  "photo": "data:image/jpeg;base64,...（可為空）",
  "storage": "fridge | freezer",
  "expiry": "2026-10-16",
  "qty": 1,
  "note": "已開封",
  "added": 1729000000000
}
```
儲存於 `localStorage`，key 為 `fridge-expiry-v1`。

## 7. 技術限制
- 單一 index.html，無需後端、無外部套件
- 可直接用瀏覽器開啟，並以 GitHub Pages 部署
- 資料只存在使用者本機瀏覽器，換裝置不會同步
